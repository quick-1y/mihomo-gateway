# Ubuntu Gateway + Mihomo

Интерактивный установщик шлюза на Ubuntu/Debian, который превращает мини-комп с двумя сетевыми портами в сетевой gateway с Mihomo.

---

## Что это такое

Схема работы:

```text
         ИНТЕРНЕТ
            │
            │ WAN
            ▼
 ┌──────────────────────┐
 │      Ubuntu          │
 │                      │
 │  wan → Интернет      │
 │  lan → 192.168.100.1 │
 │  Meta → Mihomo TUN   │
 │                      │
 │  dnsmasq             │
 │  nftables            │
 │  Mihomo              │
 └──────────┬───────────┘
            │
            │ LAN
            ▼
      192.168.100.0/24
            │
            │
            ▼
       Switch / AP
            │
┌───────────┼───────────┐
│           │           │
PC        Wi-Fi       Камеры
```

На Ubuntu остаются системные сетевые функции:

* Netplan
* DHCP/DNS через dnsmasq
* IPv4 forwarding
* NAT через nftables

В Docker работают:

* Mihomo
* MetaCubeXD

---

## Возможности

Установщик умеет:

* автоматически определить физические сетевые интерфейсы;
* назначить LAN и WAN;
* настроить LAN;
* настроить DHCP;
* включить IPv4 forwarding;
* настроить NAT;
* установить Docker Engine и Docker Compose;
* установить Mihomo в Docker;
* установить MetaCubeXD;
* настроить Mihomo API;
* запросить пароль API во время установки;
* настроить подписку Mihomo;
* проверить конфигурацию перед запуском;
* проверить состояние контейнеров и API;
* переустановить Gateway;
* удалить Gateway без удаления сетевой конфигурации;
* выполнить полное удаление и сброс сети;
* изменять настройки после установки.

# Требования

## Операционная система

Рекомендуется:

* Ubuntu 24.04 LTS
* Ubuntu 26.04
* совместимый Debian/Ubuntu-based дистрибутив

## Аппаратные требования

Минимально:

* 2 физических сетевых интерфейса;
* один интерфейс для WAN;
* один интерфейс для LAN;
* доступ к интернету во время установки.

Для Ethernet рекомендуется использовать два физических порта RJ-45.

# Установка

Установку можно выполнить полностью через SSH.

Подключитесь к мини-компьютеру:

```bash
ssh user@IP_АДРЕС
```

После подключения скачайте установщик.

```bash
curl -fsSL -o install-gateway-docker.sh https://raw.githubusercontent.com/quick-1y/mihomo-gateway/main/install-gateway-docker.sh
```

Сделайте его исполняемым:

```bash
chmod +x install-gateway-docker.sh
```

Запустите:

```bash
sudo ./install-gateway-docker.sh
```
---

# Первый запуск

При первом запуске установщик проверяет состояние сети.

Если Gateway ещё не настроен, появится:

```text
ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА СЕТИ
```

Будут настроены:

```text
LAN  → 192.168.100.1/24
WAN  → DHCP
DHCP → 192.168.100.100–192.168.100.250
```

После этого скрипт специально **останавливается**.

Это сделано для безопасной работы через SSH.

## Что нужно сделать после первого этапа

1. Отключитесь от текущей SSH-сессии.
2. Подключите компьютер к LAN-порту мини-ПК.
3. Убедитесь, что компьютер получает IP автоматически.
4. Получите адрес из диапазона:

```text
192.168.100.100–192.168.100.250
```

5. Подключитесь к мини-ПК:

```bash
ssh user@192.168.100.1
```

6. Снова запустите установщик.

На втором запуске сетевой этап будет пропущен.

# Пароль Mihomo API

Во время установки скрипт попросит задать пароль:

```text
Пароль Mihomo API
```

Пароль используется Mihomo для защиты Clash API.

В конфигурации Mihomo это:

```yaml
external-controller: 192.168.100.1:9090
secret: "ВАШ_ПАРОЛЬ"
```

Этот же пароль используется MetaCubeXD при подключении к API.

---

# MetaCubeXD

После установки веб-панель доступна по адресу:

```text
http://192.168.100.1/
```

API Mihomo:

```text
http://192.168.100.1:9090
```

Порт proxy:

```text
192.168.100.1:7890
```

В MetaCubeXD используется backend:

```text
http://192.168.100.1:9090
```

и пароль Mihomo API, который был указан во время установки.

# Подписка

Во время установки скрипт запрашивает URL подписки Mihomo.

Пример:

```text
https://example.com/subscription/xxxxx
```

Если конфигурация уже существует, можно:

```text

2) Ввести новую ссылку
```

При переустановке существующая конфигурация не должна удаляться автоматически.

# 2. Удалить Gateway

Обычное удаление удаляет только приложение:

```text
Mihomo
MetaCubeXD
Docker-контейнеры
конфигурацию Gateway
```

При этом сохраняются:

```text
Netplan
LAN
WAN
dnsmasq
DHCP
nftables
NAT
IPv4 forwarding
Docker Engine
```

Это позволяет безопасно удалить приложение и затем установить его заново.

# 3. Полное удаление + сброс сети

Этот пункт предназначен для полного возврата мини-ПК к состоянию до установки Gateway.

Будут удалены:

```text
Mihomo
MetaCubeXD
Docker Engine
Docker Compose
nftables
dnsmasq
DHCP
IPv4 forwarding
Gateway Netplan
```

После этого скрипт пытается восстановить исходную конфигурацию Netplan.

## Важно

Полный сброс сети может разорвать SSH-соединение.

После сброса устройство может стать недоступным по сети.

Перед выполнением операции скрипт требует дополнительное подтверждение.

Рекомендуется выполнять полное удаление только тогда, когда у вас есть физический доступ к мини-ПК или возможность настроить сеть другим способом.

Исходная конфигурация Netplan сохраняется в резервную копию перед изменениями.

# 5. Настройки

После установки конфигурацию можно изменять без полной переустановки.

Предусмотрены разделы:

```text
1) Подписка Mihomo
2) Пароль API / Backend
3) Настройки LAN
4) Настройки DHCP
5) Настройки NAT
6) Настройки LAN / WAN интерфейсов
```

Изменения должны проходить через последовательность:

```text
Изменить
   ↓
Проверить
   ↓
Показать изменения
   ↓
Подтвердить
   ↓
Применить
   ↓
Проверить результат
```

Для изменений сети скрипт предупреждает о возможном разрыве SSH.

# Структура файлов

После установки рабочая конфигурация находится в:

```text
/opt/mihomo-gateway/
```

Основные файлы:

```text
/opt/mihomo-gateway/
├── compose.yaml
├── .env
└── config/
    ├── config.yaml
    ├── ruleset/
    └── proxy_providers/
```

Системные настройки:

```text
/etc/netplan/01-gateway.yaml
/etc/dnsmasq.conf
/etc/nftables.conf
/etc/sysctl.d/99-router.conf
```

Резервные копии исходной конфигурации сохраняются отдельно.

# Переустановка

Переустановка не требует повторной настройки сети.

Запустите:

```bash
sudo ./install-gateway.sh
```

Выберите:

```text
1) Установить / переустановить Gateway
```

После этого скрипт:

1. проверит существующую конфигурацию;
2. проверит Docker;
3. проверит сетевые компоненты;
4. запросит пароль API;
5. предложит использовать существующую подписку;
6. обновит контейнеры;
7. выполнит проверки.

# Безопасность

Установщик изменяет сетевую конфигурацию операционной системы.

В частности, он может изменять:

```text
/etc/netplan/
/etc/dnsmasq.conf
/etc/nftables.conf
/etc/sysctl.d/
```

Поэтому:

* не запускайте скрипт на сервере, где потеря сетевого доступа критична;
* перед изменением сети используйте резервную копию;
* при работе по SSH учитывайте возможность разрыва соединения;
* при полном удалении убедитесь, что у вас есть способ получить доступ к устройству локально.

Пароль Mihomo API хранится локально на устройстве и не выводится на экран.
